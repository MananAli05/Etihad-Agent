# Etihad Garden

A modern, responsive real estate landing page for Etihad Garden, Rahim Yar Khan.

## Features

- Premium responsive landing page
- Property and facilities sections
- Interactive location section
- Virtual tour
- Lead inquiry form
- Sara AI chatbot
- Sara AI voice assistant
- Mobile responsive design

## Tech Stack

- React
- Vite
- CSS
- Groq
- ElevenLabs
